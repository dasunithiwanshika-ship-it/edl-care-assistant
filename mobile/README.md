# EDL Care Assistant – Mobile Application

This directory is reserved for the upcoming **React Native & Expo** cross-platform mobile application for Android and iOS.

## Planned Capabilities
- Native biometric authentication (Fingerprint / Face ID).
- Push notifications for scheduled power cuts and localized breakdowns.
- Camera-based meter reading and bill scanner.
- Offline-capable outage maps.
- Multilingual voice-enabled Gemini AI Assistant.
